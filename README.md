# 🎬 DVD Rental Business Analysis

## 📌 Project Overview

This project analyzes a DVD rental business using PostgreSQL and SQL.

The analysis focuses on customer behavior, movie performance, category performance, store revenue, rental trends, and customer segmentation.

The goal is to answer business questions and generate insights that could help a movie rental company understand its customers and business performance.

---

## 🛠️ Tools Used

- PostgreSQL
- pgAdmin 4
- SQL

---

## 🎯 Business Questions

The analysis answers 25 business questions, including:

### Customer Analysis
- How many customers are there?
- Which customers spend the most?
- Which customers have the highest number of rentals?
- Which customers have spent more than $150?
- How can customers be segmented based on spending?
- Which customers have never rented a movie?

### Movie & Category Analysis
- How many movies are available?
- What are the most expensive movies?
- What are the longest movies?
- Which movies are rented the most?
- Which movies generate the most revenue?
- Which movies have never been rented?
- Which categories contain the most movies?
- Which categories generate the most revenue?
- Which categories have the highest rental activity?

### Store & Revenue Analysis
- Which store generates more revenue?
- What is the monthly revenue?
- What is the monthly rental volume?
- What percentage of total revenue does each customer contribute?

### Advanced SQL Analysis
- How can customers be ranked by spending?
- Who are the top 3 customers in each store?
- What is the most popular movie in each category?
- How can customers be segmented using spending and rental behavior?
